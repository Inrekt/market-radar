# Market Radar

Телеграм-помощник по крипте: сам пингует, когда что-то началось, отвечает
разбором по запросу, ведёт архив рынка и дневник.

Отдельно от `hl-whale-bot` (китовый бот жив и работает сам) и от `chartlab`.

## Состояние

**Фаза 1 — регистраторы.** Работают три записи; бот и сканер идут следом.

| запись | частота | что пишет |
|---|---|---|
| рынок | 5 мин | все 232 перпа: цена, фандинг, открытый интерес, оборот |
| киты | 15 мин | изменения позиций 120 крупнейших счетов (только диффы) |
| поток | непрерывно | лента и стакан по топ-15, корзины по 10 секунд + крупные принты |

Записи включены раньше всего остального намеренно: ленту, стакан, историю
позиций китов и «обычный объём для этого часа» нельзя получить задним числом
ни бесплатно, ни за деньги.

## Запуск

```sh
npm install
npm run smoke                          # проверка живого API без записи
npm run record                         # запись, пока не остановят
npm run record -- --max-runtime-minutes 345   # смена для цепочки GitHub Actions
npm test && npm run typecheck
```

Данные ложатся в `state/` (в CI это worktree ветки `state`; локально — просто
папка, она в .gitignore).

## Источник данных

Hyperliquid, публичный API, без ключей и без денег. Binance не годится
основным: с американских адресов, где живут раннеры GitHub Actions, он отвечает
451.

Замеры, которые определили устройство, — в плане проекта и в заметках vault
(`Радар рынка/Что измерено на данных`). Коротко: карта ликвидаций китов
бесполезна (кросс-маржа), карты глубины стакана не будет (20 уровней на
сторону), знак дельты сверен записью (`A` — продажа, `B` — покупка).
