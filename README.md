# Market Radar

Телеграм-помощник по крипте: сам следит за рынком и пингует, когда что-то
началось; по запросу разбирает монету картинкой; ведёт архив и отчитывается,
чего стоили его собственные сигналы.

Отдельно от `hl-whale-bot` (китовый бот жив сам по себе) и от `chartlab`.

## Что он делает

| команда | что показывает |
|---|---|
| `/ta SOL 1h` | разбор структуры: ордер-блоки, разрывы, ликвидность, границы суток. Без тикера предложит то, что сейчас движется |
| `/flow SOL` | поток прямо сейчас: лента сделок, дельта, ближний стакан |
| `/digest` | сводка по рынку; утром и вечером присылает сам |
| `/score` | табель: движение после пингов против контрольной группы |
| `/status` | живой ли радар и что он видел за сутки |
| `/mute SOL 12` · `/unmute` · `/quiet` | управление шумом |
| `/threshold 0.35` | порог пинга |

Плюс сам, без запроса: пинг карточкой, когда монета выходит из спячки. Не
больше шести в час днём и двух ночью, повтор по монете не раньше четырёх часов.

## Запуск

```sh
npm install
zsh scripts/serve.sh          # бот и регистратор под надзором, с перезапуском
```

Запускать **из терминала**: на macOS фоновому заданию не дают доступ к Рабочему
столу, и процесс молча не увидит ни архив, ни токен.

Отдельно, если нужно по частям:

```sh
npm run bot        # только бот
npm run record     # регистраторы + сканер + расписание сводок
npm run render     # карточка /ta в out/, без телеграма
npm run smoke      # проверка живого API без записи
npm test && npm run typecheck
```

Токен бота — в `.env` (в git не попадает). Владельцем становится первый, кто
написал боту; остальным бот отвечает отказом.

## Из чего состоит

- **Регистраторы** — рынок целиком каждые 5 минут, позиции 120 крупнейших
  китов каждые 15, лента и стакан по топ-15 непрерывно. Включены раньше всего
  остального: ленту, стакан, историю позиций и «обычный объём для этого часа»
  нельзя получить задним числом ни бесплатно, ни за деньги.
- **Разметка** — ордер-блоки, разрывы и их инверсии, пулы ликвидности, границы
  прошлых суток. Всё считается механически; фигуры вроде «голова-плечи» не
  делаем: их детекторы субъективны и дают уверенный мусор.
- **Сканер** — восемь метрик, скор по трём сильнейшим, бюджет пингов. Метрика,
  которой не хватает архива, молчит и в оценку не входит: подставить ноль
  значит выдать выдумку за измерение.
- **Табель** — для каждого пинга движение цены на четырёх горизонтах против
  кандидатов, не прошедших порог. Без контрольной группы «после пинга цена
  прошла столько-то» не значит ничего.

Данные — Hyperliquid, публичный API, без ключей и без денег. Binance не годится
основным: с американских адресов, где живут раннеры GitHub Actions, он отвечает
451.

## Что измерено, а не предположено

- После пинга цена за час проходит 1.7% против 1.0% у контрольной группы, за
  четыре часа 2.8% против 2.0% (41 пинг, 28.08.2026). Слабейшие метрики —
  пробой уровня 0.3% и поток китов 0.6%.
- Публичный стакан отдаётся 20 уровнями на сторону — карты глубины не будет ни
  у нас, ни у платного сервиса на том же источнике.
- Цена ликвидации китовых позиций к графику не относится: счета кросс-
  маржинальные, ликвидация считается по всему счёту.
- `A` в ленте — агрессивная продажа, `B` — покупка. Сверено записью.

Подробности решений — в заметках vault (`Радар рынка`) и в комментариях к коду.
